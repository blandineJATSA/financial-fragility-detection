# Convention de commits

Ce projet suit les Conventional Commits.

feat:     nouvelle fonctionnalite
fix:      correction de bug
docs:     documentation uniquement
test:     ajout ou modification de tests
refactor: changement de code sans changement de comportement
chore:    taches de maintenance (config, dependances...)
ci:       integration continue

Exemples :
  git commit -m "feat: add synthetic client generator"
  git commit -m "fix: correct overdraft ratio calculation"
  git commit -m "docs: add business context"
